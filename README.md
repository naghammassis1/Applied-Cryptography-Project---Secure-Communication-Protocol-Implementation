🔐 Secure Communication Protocol Implementation

📌 Overview

This project implements a secure communication system that ensures confidentiality, authentication, and data integrity using modern cryptographic techniques.

⚙️ Features

Secure message encryption using AES (CBC mode)

Secure key exchange using Diffie-Hellman

Authentication using RSA digital signatures

Data integrity using SHA-256 hashing

End-to-end encrypted communication between client and server

🧪 Functionality

Encrypts and decrypts messages securely

Establishes a shared session key without transmitting it directly

Verifies identity using digital signatures

Ensures no plaintext is exposed during transmission

🛠️ Technologies Used

Python

AES Encryption

RSA

Diffie-Hellman

SHA-256

▶️ How to Run

Run the server:

python server.py

Run the client:

python client.py

Send secure messages between client and server
